# Политика конфиденциальности — Autonova Orders Tagger

**Дата вступления в силу:** 28 мая 2026 г.

## 1. Какие данные собираются

Расширение собирает и обрабатывает следующие данные:

- **Имя пользователя и цвет бейджа** — вводятся вручную в настройках расширения (popup) и используются для отображения имени менеджера рядом с заказом.
- **Данные о заказах** — номер заказа (ЗК-...), сумма, дата, количество товаров, коды товаров, код клиента. Эти данные считываются со страницы `autonovad.ua` и отправляются в общую базу данных для определения, кто из менеджеров оформил заказ.
- **Отладочные логи** — записываются локально в браузере. Отправляются на сервер **только по явному запросу пользователя** (кнопка «Надіслати логи розробнику»).

## 2. Цель сбора данных

Единственная цель — показывать в списке истории заказов autonovad.ua имя менеджера, который оформил конкретный заказ. Без обмена этими данными между менеджерами расширение не может работать.

## 3. Где хранятся данные

Все данные хранятся в облачной базе данных **Supabase** (`zsnecazcpmbqezlylnjr.supabase.co`). Локально в браузере хранятся: имя пользователя, цвет бейджа, кэш имён заказов, уникальный идентификатор установки (installId) и отладочные логи.

## 4. Передача третьим лицам

Данные не передаются третьим лицам за пределами Supabase. Supabase используется исключительно как backend для синхронизации заказов между менеджерами.

## 5. Управление данными

Пользователь может в любой момент:
- Изменить имя и цвет в настройках расширения.
- Очистить локальный кэш и логи через вкладку «Діагностика».
- Удалить расширение — при этом локальные данные удаляются автоматически.

## 6. Контакты

По вопросам, связанным с данными: напишите через вкладку «Діагностика» → «Надіслати логи розробнику».
